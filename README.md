# ToonaFlix
Combined netflix and webtoon application. (Side-Project Only)

This project is made only for school project purposes and have no intentions to publish it.

To make the .php file work. Follow the ff.
1.) Install xampp
2.) Run MySQL Database
3.) Run Apache Web Server
4.) Run Localhost/phpmyadmin
  - import the schema.sql inside the database (click new -> import -> chose schema.sql -> add)
5.) Run localhost/Toonaflix
